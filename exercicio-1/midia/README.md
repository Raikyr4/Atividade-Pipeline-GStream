# Vídeo de exemplo e atribuição

`exemplo.webm` é uma cópia do trailer **Sintel**, obra da **Blender Foundation / Durian Open Movie Project**. O vídeo existente é usado como entrada; a aplicação não gera nem modifica o arquivo original.

- [Arquivo disponibilizado pelo GStreamer](https://gstreamer.freedesktop.org/data/media/sintel_trailer-480p.webm)
- [Projeto e licença informada pelo autor](https://durian.blender.org/about/)
- [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/)

Fonte baixada em 30/09/2026. As comparações produzidas pelo programa são adaptações: redução para 320 × 180, ajuste para 10 FPS e conversão para cinza. Ao apresentar ou distribuir imagens derivadas, mantenha esta atribuição. A execução de exemplo começa no segundo 5 para evitar a abertura preta; o arquivo permanece completo e inalterado.

Você pode usar outro vídeo com `scripts/executar.ps1 -Video "CAMINHO"`. O funcionamento depende dos codecs disponíveis no GStreamer da máquina.
